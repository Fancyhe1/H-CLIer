# H CLIer 安装指南

> 本文档详细介绍如何在 Windows 上安装 H CLIer。

---

## 系统要求

- **操作系统**：Windows 10 或 Windows 11（64 位）
- **内存**：至少 4GB RAM
- **磁盘空间**：至少 100MB 可用空间
- **前置依赖**：Node.js >= 18、Claude Code CLI

---

## 方式一：下载安装包（推荐）

### 1. 下载安装包

访问 GitHub Releases 页面：https://github.com/Fancyhe1/H-CLIer/releases

下载最新版本的安装包：`H-CLIer_0.3.2_x64-setup.exe`

### 2. 运行安装程序

1. 双击下载的安装包
2. 如果出现 Windows Defender 警告：
   - 点击"更多信息"
   - 点击"仍要运行"
3. 按照安装向导提示完成安装

### 3. 首次启动

1. 双击桌面快捷方式或从开始菜单启动
2. 首次启动会自动检测 Claude Code CLI
3. 如果未检测到，会提示安装

---

## 方式二：从源码构建

### 1. 安装依赖

```bash
# 安装 Node.js
# 下载地址：https://nodejs.org/

# 安装 Rust
# 下载地址：https://www.rust-lang.org/tools/install

# 安装 Claude Code CLI
npm install -g @anthropic-ai/claude-code
```

### 2. 克隆仓库

```bash
git clone https://github.com/Fancyhe1/H-CLIer.git
cd H-CLIer
```

### 3. 安装前端依赖

```bash
cd aicoder
npm install
```

### 4. 构建生产版本

```bash
npm run tauri:build
```

构建产物位于 `aicoder/src-tauri/target/release/bundle/nsis/`。

## 常见安装问题

### Q1：安装时提示"Windows 已保护你的电脑"

这是因为新软件需要时间建立信誉。解决方法：

1. 点击"更多信息"
2. 点击"仍要运行"
3. 如果仍有问题，可以暂时关闭 Windows Defender 实时保护

### Q2：安装失败

可能原因：

1. **权限不足**：以管理员身份运行安装程序
2. **磁盘空间不足**：清理磁盘空间
3. **杀毒软件拦截**：暂时关闭杀毒软件

### Q3：启动时崩溃

可能原因：

1. **WebView2 未安装**：Windows 10/11 通常已预装，如果没有，请从 Microsoft 官网下载
2. **显卡驱动问题**：更新显卡驱动
3. **系统版本过低**：确保 Windows 版本 >= 10

## 卸载

1. 打开"控制面板" → "程序和功能"
2. 找到 "H CLIer"
3. 右键选择"卸载"
4. 按照提示完成卸载
