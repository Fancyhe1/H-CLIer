## 一、项目定位

### 1.1 核心价值主张

**一句话描述**：
> H CLIer — Windows 上 Claude Code CLI 的图形化管理工具，让 AI 编程助手更高效。

**核心卖点**：
- **Windows 原生支持**：为 Windows 用户优化的 Claude Code 体验
- 多会话管理：同时管理多个 Claude 项目
- 终端仿真：原生 PTY，历史回放
- Token 追踪：实时监控 AI 消耗
- 项目检查点：快照 + 回滚，安全无忧
- 聊天记录：JSONL 解析，Markdown 渲染

### 1.2 目标受众

| 人群 | 特征 | 痛点 |
|------|------|------|
| **Windows Claude Code 用户** | Windows 平台使用 Claude CLI | 终端体验差，缺乏图形化管理 |
| Claude Code 用户 | 使用 Claude CLI 进行编程 | 终端体验差，无法管理多会话 |
| AI 编程爱好者 | 探索 AI 辅助开发 | 缺乏统一管理工具 |
| 独立开发者 | 多项目并行开发 | 需要高效的工作流 |
| 技术博主 | 关注 AI 工具生态 | 寻找值得分享的工具 |

### 1.3 竞品分析

| 工具 | 特点 | H CLIer 差异化 |
|------|------|----------------|
| Claude Code CLI | 原生终端 | 图形化 + 多会话管理 + **Windows 优化** |
| Cursor | IDE 集成 | 专注于 Claude Code，更轻量 |
| Continue | 多模型支持 | 更深度的 Claude 集成 |
| Windows Terminal | 通用终端 | 专注 Claude Code 场景 |

**Windows 用户痛点**：
- Claude Code CLI 在 Windows 终端体验较差
- 缺乏图形化管理界面
- 多项目切换不便
- Token 用量难以追踪

## 五、产品描述

### 5.1 短描述（100字）

> H CLIer 是一款专为 Windows 用户设计的 Claude Code CLI 图形化管理工具。基于 Tauri 2.x 构建，支持多会话管理、终端仿真、Token 用量追踪、项目检查点等功能，让 Windows 上的 AI 编程体验更高效。

### 5.2 中描述（300字）

> H CLIer 是一款专为 Windows 平台 Claude Code CLI 用户设计的图形化管理工具。它解决了 Windows 终端环境下管理多个 AI 编程会话的痛点，提供了企业级的桌面管理体验。
>
> **核心功能**：
> - **Windows 原生支持**：为 Windows 优化的 PTY 终端，解决 Windows 终端兼容性问题
> - **多会话管理**：基于 SQLite 的持久化存储，支持工作区分组、拖拽排序、收藏标记
> - **终端仿真**：原生 PTY 实例，每会话独立终端，支持历史回放
> - **Token 追踪**：实时监控 AI 消耗，按模型分别计费，支持日/周/月统计
> - **项目检查点**：快照整个项目目录，支持文件级 Diff 对比与一键回滚
> - **聊天记录**：解析 Claude 的 JSONL 格式，Markdown 渲染，搜索过滤
>
> **技术栈**：React 19 + TypeScript + Tauri 2 + Rust + SQLite
>
> **适用人群**：Windows Claude Code 用户、AI 编程爱好者、独立开发者

### 5.3 长描述（GitHub About）

