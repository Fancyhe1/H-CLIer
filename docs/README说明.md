## 使用场景

### GitHub 仓库页面

当用户访问 https://github.com/Fancyhe1/H-CLIer 时，看到的是 `README.md`：

- 快速了解项目是什么

- 下载安装包
- 查看截图

### 深入了解

当用户需要详细了解项目时，可以查看 `README.full.md`：

- 完整的功能说明

- 贡献指南

## 更新说明

### 更新 README.md

如果需要更新 GitHub 仓库页面的 README：

1. 编辑 `README.md`
2. 提交并推送
3. GitHub 页面会自动更新

### 更新 README.full.md

如果需要更新完整文档：

1. 编辑 `README.full.md`
2. 提交并推送
