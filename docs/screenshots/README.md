## 截图规范

### 尺寸

- **主界面截图**：1920x1080 或 1280x720
- **功能截图**：800x600 或 1024x768
- **GIF**：宽度 800px，帧率 15fps

### 格式

- **静态图**：PNG（推荐）或 JPG
- **动态图**：GIF

### 内容要求

1. **清晰**：确保文字和 UI 元素清晰可见
2. **整洁**：关闭无关的窗口和通知
3. **示例数据**：使用有意义的示例数据
4. **主题**：使用亮色主题（更易阅读）

## 截图工具推荐

### Windows

- **Snipping Tool**：Windows 自带
- **ShareX**：免费，支持 GIF 录制
- **OBS Studio**：免费，专业录屏

### macOS

- **Screenshot**：macOS 自带
- **Kap**：免费，GIF 录制
- **CleanShot X**：付费，功能强大

### Linux

- **GNOME Screenshot**：GNOME 自带
- **Flameshot**：免费，功能丰富
- **Kazam**：免费，支持录屏
