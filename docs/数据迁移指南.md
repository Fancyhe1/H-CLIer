# H CLIer 数据迁移指南

## 为什么需要迁移？

v0.3.2 版本将产品标识符从 `com.hcl-ier.dev` 更改为 `com.hcl-ier`（去掉了 "Dev" 后缀）。Tauri 根据标识符决定数据存储目录，因此新版本会使用全新的数据目录，不会自动读取旧版本数据。

**旧版本数据目录**: `%APPDATA%\com.hcl-ier.dev\`
**新版本数据目录**: `%APPDATA%\com.hcl-ier\`

## 数据目录结构

| 文件/目录 | 说明 |
|----------|------|
| `sessions.db` | 会话数据库（SQLite），包含所有会话记录 |
| `config/` | 应用配置文件（主题、快捷键、Claude CLI 配置等） |
| `checkpoints/` | 会话检查点/快照 |
| `terminal_logs/` | 终端历史日志 |
| `agents/` | Agent Hub 数据 |
| `web_access_token` | Web 访问令牌 |

## 迁移方法

### 方法一：命令行（推荐）

打开 PowerShell，执行以下命令：

```powershell
# 1. 定义目录路径
$oldDir = "$env:APPDATA\com.hcl-ier.dev"
$newDir = "$env:APPDATA\com.hcl-ier"

# 2. 备份新目录（以防万一）
$backup = "$env:APPDATA\com.hcl-ier.backup-$(Get-Date -Format 'yyyyMMddHHmmss')"
Copy-Item -Path $newDir -Destination $backup -Recurse
Write-Host "已备份到: $backup"

# 3. 复制数据
Copy-Item "$oldDir\sessions.db" "$newDir\" -Force
Copy-Item "$oldDir\config\*" "$newDir\config\" -Recurse -Force
Copy-Item "$oldDir\checkpoints\*" "$newDir\checkpoints\" -Recurse -Force
Copy-Item "$oldDir\terminal_logs\*" "$newDir\terminal_logs\" -Recurse -Force
Copy-Item "$oldDir\web_access_token" "$newDir\" -Force
Copy-Item "$oldDir\agents" "$newDir\" -Recurse -Force

Write-Host "迁移完成！请重启 H CLIer。"
```

### 方法二：手动复制

1. 打开文件资源管理器，地址栏输入 `%APPDATA%` 回车
2. 进入 `com.hcl-ier.dev` 文件夹
3. 复制以下文件/文件夹：
   - `sessions.db`
   - `config/`
   - `checkpoints/`
   - `terminal_logs/`
   - `agents/`
   - `web_access_token`
4. 返回上一级，进入 `com.hcl-ier` 文件夹
5. 粘贴覆盖
6. 重启 H CLIer

## 验证

迁移后重启应用，检查：
- [ ] 会话列表是否恢复
- [ ] 主题/快捷键等配置是否保留
- [ ] 检查点是否可用

## 清理旧数据

确认新版本一切正常后，可以删除旧目录释放空间：

```powershell
Remove-Item -Path "$env:APPDATA\com.hcl-ier.dev" -Recurse -Force
```

以及备份目录：

```powershell
Remove-Item -Path "$env:APPDATA\com.hcl-ier.backup-*" -Recurse -Force
```

## 常见问题

**Q: 迁移后会话数据丢失了怎么办？**
A: 旧目录数据不会被删除，可以重新执行迁移。如果新目录有问题，可以从备份恢复。

**Q: 以后版本更新还需要迁移吗？**
A: 不需要。标识符已改为 `com.hcl-ier`，后续版本会继续使用同一数据目录，自动兼容。

**Q: 新版本已经用了一段时间，有新数据怎么办？**
A: 迁移会覆盖新目录中的文件。如果新版本已有重要数据，先手动备份新目录，再执行迁移，然后手动合并需要的内容。
