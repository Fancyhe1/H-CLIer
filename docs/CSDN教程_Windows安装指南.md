# H CLIer Windows 安装指南：5 分钟上手 Claude Code 图形化管理工具

> 本文介绍如何在 Windows 上安装和使用 H CLIer，一款专为 Claude Code CLI 设计的图形化管理工具。

---

## 前言

大家好，今天给大家分享一个我开发的工具：**H CLIer**。

作为 Windows 用户，使用 Claude Code CLI 时是否遇到这些问题：

- 终端体验差，多项目管理混乱
- Token 用量难以追踪
- 会话历史容易丢失
- 缺乏项目快照功能

H CLIer 就是为了解决这些问题而生的。本文将详细介绍如何在 Windows 上安装和使用它。

---

## 一、环境准备

### 1.1 系统要求

- Windows 10 或 Windows 11
- 64 位操作系统
- 至少 4GB 内存
- 100MB 可用磁盘空间

### 1.2 前置依赖

在使用 H CLIer 之前，需要先安装 Claude Code CLI：

```bash
# 安装 Node.js（如果还没有）
# 下载地址：https://nodejs.org/

# 安装 Claude Code CLI
npm install -g @anthropic-ai/claude-code
```

验证安装：

```bash
claude --version
```

## 二、下载安装 H CLIer

### 2.1 下载安装包

1. 访问 GitHub Releases 页面：https://github.com/Fancyhe1/H-CLIer/releases
2. 下载最新版本的安装包：`H-CLIer_0.3.2_x64-setup.exe`
3. 文件大小约 5MB

### 2.2 安装步骤

1. **双击安装包**
   - 如果出现 Windows Defender 警告，点击"更多信息" → "仍要运行"
   - 这是因为新软件需要时间建立信誉

2. **选择安装目录**
   - 默认安装到 `C:\Program Files\H CLIer`
   - 可以自定义安装路径

3. **完成安装**
   - 勾选"创建桌面快捷方式"
   - 点击"完成"

### 2.3 首次启动

1. 双击桌面快捷方式或从开始菜单启动
2. 首次启动会自动检测 Claude Code CLI
3. 如果未检测到，会提示安装

## 六、常见问题

### Q1：安装时提示"Windows 已保护你的电脑"

这是因为新软件需要时间建立信誉。解决方法：

1. 点击"更多信息"
2. 点击"仍要运行"
3. 如果仍有问题，可以暂时关闭 Windows Defender 实时保护

### Q2：Claude Code CLI 未检测到

确保已正确安装 Claude Code CLI：

```bash
# 检查是否安装
claude --version

# 如果未安装
npm install -g @anthropic-ai/claude-code

# 如果已安装但未检测到，可以手动配置路径
# 设置 → Claude CLI → 自定义路径
```

### Q3：终端显示乱码

Windows 终端编码问题。解决方法：

1. 打开设置
2. 选择"终端"选项卡
3. 将编码设置为 "UTF-8"

### Q4：Token 统计不准确

Token 统计基于 Claude 的 JSONL 文件解析，可能有以下原因：

1. **文件未更新**：Claude 可能还在写入，等待几秒后刷新
2. **文件路径错误**：检查 Claude 的会话目录是否正确
3. **格式变更**：Claude 更新了 JSONL 格式，等待 H CLIer 更新

### Q5：检查点回滚失败

可能原因：

1. **文件被占用**：关闭正在使用这些文件的程序
2. **权限不足**：以管理员身份运行 H CLIer
3. **磁盘空间不足**：清理磁盘空间

## 七、高级技巧

### 7.1 使用工作区

将相关会话组织到工作区中：

1. 右键侧边栏空白处
2. 选择"新建工作区"
3. 输入工作区名称（如"前端项目"）
4. 将会话拖拽到工作区中

### 7.2 会话导出

将会话导出为 JSON 文件：

1. 右键会话
2. 选择"导出"
3. 选择保存位置
4. 导出的文件可以导入到其他 H CLIer 实例

### 7.3 自定义主题

支持三种主题模式：

- **亮色模式**：适合白天使用
- **暗色模式**：适合夜间使用
- **跟随系统**：自动切换

设置路径：设置 → 外观 → 主题

### 7.4 快速启动

创建桌面快捷方式后，可以：

1. 固定到任务栏
2. 设置开机自启
3. 使用快捷键启动（需要在设置中配置）

## 八、性能优化建议

### 8.1 减少内存占用

- 关闭不使用的会话
- 定期清理检查点
- 限制终端历史记录长度

### 8.2 提高启动速度

- 减少开机自启项
- 使用 SSD 硬盘
- 保持软件更新

### 8.3 优化网络

如果使用代理：

1. 打开设置
2. 选择"网络"选项卡
3. 配置代理设置

## 九、更新与卸载

### 9.1 检查更新

H CLIer 会自动检查更新：

1. 启动时自动检查
2. 手动检查：帮助 → 检查更新
3. 发现新版本后会提示下载

### 9.2 卸载

1. 打开"控制面板" → "程序和功能"
2. 找到 "H CLIer"
3. 右键选择"卸载"
4. 按照提示完成卸载
