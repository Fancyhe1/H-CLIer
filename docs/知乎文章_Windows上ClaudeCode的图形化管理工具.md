# Windows 上 Claude Code 的图形化管理工具：H CLIer

> 作为 Windows 用户，你是否也在用 Claude Code CLI 时遇到过这些问题？终端体验差、多项目管理混乱、Token 用量难以追踪？本文介绍一个专为 Windows 用户设计的解决方案。

---

## 背景

### Claude Code CLI 的痛点

[Claude Code CLI](https://docs.anthropic.com/en/docs/claude-code) 是 Anthropic 推出的 AI 编程助手命令行工具，它让开发者能够在终端中与 Claude 进行交互式编程。

然而，作为 Windows 用户，我在使用过程中遇到了几个明显的问题：

1. **终端体验差**：Windows Terminal 虽然有所改进，但与 macOS/Linux 的终端相比，体验仍有差距
2. **多项目管理混乱**：同时进行多个项目时，需要打开多个终端窗口，难以管理
3. **Token 用量难以追踪**：Claude Code 按 Token 计费，但官方没有提供直观的用量统计
4. **会话历史丢失**：关闭终端后，之前的对话历史难以恢复
5. **缺乏项目快照**：AI 修改代码后，如果想回滚到之前的状态，操作繁琐

### 寻找解决方案

我尝试了一些现有的工具，但发现：

- **Cursor**：功能强大，但它是独立的 IDE，与 Claude Code CLI 的使用方式不同
- **Continue**：支持多模型，但对 Claude 的支持不够深入
- **Windows Terminal**：通用终端，缺乏 Claude Code 特定的管理功能

于是，我决定自己动手，开发一个专为 Claude Code CLI 设计的图形化管理工具，特别针对 Windows 用户优化。

## H CLIer 介绍

### 什么是 H CLIer？

H CLIer 是一款基于 [Tauri 2.x](https://tauri.app) 的跨平台桌面应用，为 Claude Code CLI 提供图形化管理界面。

**核心理念**：让 Windows 用户的 AI 编程助手从终端进入 IDE 级体验。

### 技术栈选择

| 层级 | 技术 | 选择理由 |
|------|------|----------|
| **桌面框架** | Tauri 2 | 包体积小（~5MB vs Electron ~150MB），内存占用低 |
| **前端** | React 19 + TypeScript | 生态成熟，类型安全 |
| **后端** | Rust | 内存安全，高性能 |
| **终端** | xterm.js + portable-pty | 成熟的终端仿真方案 |
| **数据库** | SQLite | 零配置，嵌入式 |

为什么选择 Tauri 而不是 Electron？

- **包体积**：Tauri ~5MB vs Electron ~150MB
- **内存占用**：Tauri ~50MB vs Electron ~200MB+
- **安全性**：Tauri 细粒度权限控制
- **原生集成**：Rust 后端提供更好的系统集成

- 工作区分组 + 拖拽排序

- 命令面板（`Ctrl+K`）快速切换

### 2. 终端仿真

**痛点**：Windows 终端体验差，历史记录容易丢失。

**解决方案**：

- 基于 `portable-pty` 的原生 PTY 实例
- 每会话独立终端，互不干扰
- 终端历史回放（重新打开会话时恢复之前的输出）
- 智能剪贴板（`Ctrl+C` 复制选中 / 发送中断信号）

```rust
// 核心实现：PTY 管理
pub struct PtyManager {
    instances: HashMap<String, PtyInstance>,
    log_dir: PathBuf,
}

impl PtyManager {
    pub fn create_pty(&mut self, session_id: &str, cols: u16, rows: u16) -> Result<()> {
        let pty = native_pty_system().openpty(PtySize {
            rows,
            cols,
            pixel_width: 0,
            pixel_height: 0,
        })?;

        // 记录终端输出到日志文件
        let log_path = self.log_dir.join(format!("{}_history.log", session_id));
        // ...

        Ok(())
    }
}
```

## Windows 特定优化

作为 Windows 用户，我特别关注了以下优化：

### 1. PTY 终端兼容性

Windows 的 PTY 实现与 Unix 系统不同，`portable-pty` 库提供了跨平台的 PTY 支持，但在 Windows 上仍有一些特殊处理：

```rust
// Windows 特定处理
#[cfg(target_os = "windows")]
use std::os::windows::process::CommandExt;

// 隐藏终端窗口
Command::new("cmd")
    .args(["/C", "start", "", &path])
    .creation_flags(0x08000000)  // CREATE_NO_WINDOW
    .spawn()?;
```

### 2. 安装包体验

使用 NSIS 打包，提供原生 Windows 安装体验：

- 一键安装，无需额外依赖
- 支持自定义安装目录
- 自动创建桌面快捷方式
- 支持卸载程序

### 3. Windows Defender 兼容

由于是新软件，可能会被 Windows Defender 误报。解决方案：

- 代码签名（需要购买证书）
- 提交到 Microsoft 进行白名单审核
- 在 README 中说明情况

## 使用体验

### 安装

1. 前往 [GitHub Releases](https://github.com/Fancyhe1/H-CLIer/releases) 下载最新版本
2. 运行 `H-CLIer_0.3.2_x64-setup.exe`
3. 按照提示完成安装

### 首次使用

1. 启动 H CLIer
2. 点击"新建会话"
3. 选择项目目录
4. 输入会话标题
5. 开始与 Claude 对话

### 日常使用

- `Ctrl+K`：打开命令面板，快速切换会话
- `Ctrl+C`：复制选中内容 / 发送中断信号
- `Ctrl+Shift+T`：新建终端会话
- `Ctrl+Shift+S`：创建检查点
